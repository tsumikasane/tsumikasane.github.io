プライバシーポリシー

制定日：2026年11月21日

つみかさね（以下「このアプリ」）は、使う人の情報を、次のように扱います。

1. 集める情報

  • アカウント：メールアドレスとパスワード。パスワードは Google の Firebase が暗号にして保管するので、このアプリや運営者には見えません。
  • 同期する記録：ログインしているあいだ、記録（ToDo・予定・日記・食事・体重・家計簿など）と設定を、端末どうしでそろえるためにサーバーに保存します。
  • 通知：通知アラームを使うとき、その端末の通知の宛先と、通知する時刻・予定の名前。
  • 場所：天気を出すとき、場所（緯度と経度、または探した地名）を天気と地名のサービスに送ります。記録やメールアドレスは送りません。

写真・ファイル・「端末の中のコピー」は、その端末の中だけに保存し、サーバーには送りません。ログインしないで使うときは、記録はすべてその端末の中だけにあります。

2. 使い道

  • ログインした端末どうしで、記録をそろえるため
  • 通知アラームを届けるため
  • メールアドレスの確認や、パスワードを忘れたときのメールを送るため
  • 天気を出すため

広告や、利用状況の分析には使いません。集めた情報を売ることもありません。

3. 情報をあずけるサービス

  • Google Firebase（Authentication・Cloud Firestore）：アカウントと、同期する記録
  • Cloudflare（Workers）：通知の宛先と、通知の内容
  • Open-Meteo・国土地理院：天気と地名（場所だけ）
  • GitHub Pages：このアプリの配信（ページを開いた記録が GitHub に残ることがあります）

これらのサービスは、日本の外のサーバーを使うことがあります。

4. ほかの人にわたすこと

法令にもとづく場合をのぞいて、本人の同意なしに、集めた情報をほかの人や会社にわたしません。

5. 運営者が見られるもの

運営者は、サーバーの管理画面で、登録されたメールアドレスと、保存された記録を見られるしくみになっています。問い合わせに答えるとき、不具合を直すとき、法令で求められたときのほかは、記録を見ません。

6. 情報を消す

  • 「同期」の「アカウントを消す（退会）」で、アカウントと、サーバーにある記録をすべて消せます。通知サーバーにある、そのアカウントの端末の情報も消えます。
  • 「ログアウトして、この端末の記録を消す」で、その端末にある記録を消せます。

7. 守るためにしていること

通信はすべて暗号化（HTTPS）しています。サーバーの記録は、ログインした本人しか読み書きできないように設定しています。

8. このポリシーを変えるとき

変えるときは、このページを書きかえ、制定日の下に改定日を書きます。大きく変えるときは、アプリの中でもお知らせします。
