# 消した機能（使う人が消すと決めたもの）

ここにある機能は、使う人が「使わない」と決めて消したものです。どのチャットも、**同じ機能や、ほとんど同じ機能を足しません**。似ているかどうか迷うときは、足す前に使う人に確かめます。

消すのは、使う人が指示した機能だけです。チャットが自分の判断で機能を消すことはしません。消すときも、保存してある記録（データ）は消さずに残し、画面と動きだけを消します（使う人が記録も消すと言ったときを除く）。

- 天気のページの「次の夏至・冬至」は、暦と同じ太陽の位置の計算（`h4SunLon`・`h4At`）を使っているので、その計算は残してあります。
- 日記の「季節の言葉」（祝日・二十四節気・雑節）は、別の機能なので残してあります。
- つみかさねのページのつみねこ（階段のつみねこ）や、目標のつみねこの応援は、別の機能なので残してあります。
- 天気のページの「次の休み」と、バイトの「次の休み」（シフトから数えるもの）は、別の機能なので残してあります。土日・祝日の判定（`h6IsOff`）も、天気とタイルの「出すとき」が使うので残してあります。
- カレンダーの予定の声での入力と、ルーティーンの声でのチェックは、別の機能なので残してあります。
- きょうのカウントダウンのタイルは、カウントダウンの予定がないとき、使いかたの説明（「予定の『カウントダウン』をオンにすると…」）の代わりに、次の予定まであと何日かを出すようにしました（2026-11-16、使う人の指示）。
- 家計簿の貸し借りで記録したもの（設定の `loans`）は消さずに残してあります（画面には出ません）。バイトの「代わりの貸し借り」（バイト その13 ⑥：シフトを代わった・代わってもらった回数）は別の機能なので残してあります。
- 家計簿の「支出のカレンダー」（家計簿 ①〜⑩ ⑦）は消したのではなく、使う人の指示で「収入と支出のカレンダー」に変えました（2026-11-18）。日ごとに、収入（＋）と支出（固定費もふくむ）の両方を出します。支出の多さで日を塗る形には戻しません。
- ほしいもの・働く前のチェック・借りているもの・できるようになったことで記録したもの（設定の `wants`、バイト先の `terms`・`lent`・`skills`）と、定期代（バイト先の `passCost`）は、消さずに残してあります（画面には出ません）。シフト希望の印（この端末の `bt3Ask`）も残してあります。
- シフト希望の「締め切りのお知らせ」（バイト その2 ⑨）と「シフト希望を出したか」（バイト その16 ④）は、別の機能なので残してあります。「シフト希望とのちがい」（バイト その11 ③）も残してあります（前につけた印がある月だけ出ます）。
- バイトの「何時間分？」（バイト その2 ⑩：値段が何時間分の時給かを出す道具）は、ほしいものとは別の機能なので残してあります。定期券の期限（バイト その16 ③）も残してあります。
