# 消した機能（使う人が消すと決めたもの）

ここにある機能は、使う人が「使わない」と決めて消したものです。どのチャットも、**同じ機能や、ほとんど同じ機能を足しません**。似ているかどうか迷うときは、足す前に使う人に確かめます。

消すのは、使う人が指示した機能だけです。チャットが自分の判断で機能を消すことはしません。消すときも、保存してある記録（データ）は消さずに残し、画面と動きだけを消します（使う人が記録も消すと言ったときを除く）。
